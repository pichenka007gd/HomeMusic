# Изменения Android-приложения

Предлагайте изменения HomeMusic через issues и pull requests в
[HomeMusic-public](https://github.com/justman-1/HomeMusic-public). Для крупного изменения сначала опишите задачу в issue.
Один PR должен решать одну задачу.

## Сборка и проверки

Окружение, адреса своего сервера и подпись описаны в [README.md](README.md). Для изменения приложения выполните из `android/`:

```powershell
.\gradlew testHomemusicDebugUnitTest assembleHomemusicDebug
```

В Linux/macOS используйте `./gradlew` с теми же задачами. Новое и изменённое поведение проверяйте тестами;
не пропускайте и не ослабляйте существующие тесты ради успешного прогона. В PR укажите выполненные проверки и ограничения
проверки. Для изменений интерфейса приложите скриншоты до и после, для исправления — сценарий воспроизведения.

Если изменение затрагивает Хаб, PWA или их взаимодействие с приложением, проверьте также соответствующую часть сервиса
по [корневому руководству](../CONTRIBUTING.md). При изменении контракта обновляйте [hub/API.md](../hub/API.md).

## Структура кода

- Дополнения HomeMusic находятся в `app/src/main/java/com/eddyizm/tempus/homemusic/`.
- Flavor `homemusic` и его ресурсы находятся в `app/src/homemusic/`.
- Строки HomeMusic — в `app/src/main/res/values/strings_homemusic.xml`.
- JVM-тесты — в `app/src/test/`; для HomeMusic используется задача `testHomemusicDebugUnitTest`.

Сохраняйте принятый стиль кода. Комментарии и сообщения коммитов пишите по-английски. Изменения общего кода Tempus
держите небольшими, чтобы последующие обновления апстрима было проще переносить.

## Личные данные и отладка

Не добавляйте ключи подписи, пароли, токены, коды приглашений, cookie, личные адреса серверов или пользовательские базы.
Адреса в тестах должны быть примерами (`example.com`, `192.0.2.0/24`), данные аккаунтов — вымышленными.
Проверяйте `git diff` и состав staged-файлов перед коммитом; локальные настройки и результаты сборки в PR не нужны.

Release-сборка использует R8. Для разбора её стека нужен `app/build/outputs/mapping/homemusicRelease/mapping.txt`
**от той самой сборки**, в которой возникла ошибка. До публикации логов и скриншотов удалите учётные данные
и информацию пользователей.
