# Публичный запуск HomeMusic

1. Веб-Хаб на `music.pichenka007gd.ru` → `8080`; Navidrome на `hub.pichenka007gd.ru` → `4533`. Настроить перенаправление адресов на существующем шлюзе, проверить HTTPS, доверенный прокси и передачу IP.
2. Без аккаунта: библиотека и внешний поиск Deezer, воспроизведение и скачивание на устройство. Отдельный API и квоты по HMAC(IP), без выдачи сессии. Проверка: запросы гостя к закрытым API возвращают `401`, превышение квоты — `429`.
3. Веб и Android: регистрация с подтверждённым Google ID-токеном при `GOOGLE_OPEN_SIGNUP=true`. Браузер не получает пароль Navidrome. Для запуска нужен Google Client ID и JavaScript origin веб-Хаба.
4. Главная показывает счётчик Navidrome. Android предзаполняет два HTTPS-адреса, сохранённые подключения не мигрируются.
5. Импорт Яндекс Музыки: общий лимит создания и обновления раз в семь дней на аккаунт, не зависит от удаления импорта.

Перед релизом: резервная копия SQLite, пересборка Hub, затем проверка `music…/healthz`, `hub…/ping`, гостевого поиска и HTTP Range. Проверить, что клиентские адреса корректны и поддельные заголовки из недоверенного источника игнорируются. Не выкладывать неподписанный APK как обновление существующей версии.
